Matplotlib vs Seaborn: the big picture

🧱 Matplotlib

  • The foundation library (2003). Almost every Python plotting tool is built on it.
  • Gives you full control of every pixel: lines, ticks, text, layout.
  • Needs more code to make a chart look polished.
  • Best for: custom figures, publications, engineering plots, and any chart type you can imagine.

🎨 Seaborn

  • A high-level library built on top of Matplotlib.
  • Works directly with pandas DataFrames and column names.
  • Comes with good-looking themes and statistical plots (smooth curves, best-fit lines, uncertainty bands).
  • Best for: exploratory data analysis (EDA) and statistical summaries.
👩‍🏫 Teaching analogyMatplotlib is a box of LEGO bricks: you can build anything, one brick at a time. Seaborn is a LEGO kit: it builds a finished model for you, and it's still made of the same bricks, so you can change any of them afterwards with Matplotlib.

Module 1 · Basic Plotting

From zero to your first chart, one line of code at a time.

🎯 Learning objectives: students will be able to…

Same chart: Matplotlib vs Seaborn

Both draw the same chart. Matplotlib takes the values directly. Seaborn takes a table and the column names.

MATPLOTLIB
import matplotlib.pyplot as plt
days  = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri']
sales = [23, 45, 12, 36, 41]

plt.bar(days, sales, color='skyblue')
plt.title('Sales per day')
plt.xlabel('Day')
plt.ylabel('Units sold')
plt.show()
SEABORN (DataFrame + column names)
import seaborn as sns
import pandas as pd
df = pd.DataFrame({'day': ['Mon','Tue','Wed','Thu','Fri'],
                   'sales': [23, 45, 12, 36, 41]})

sns.barplot(data=df, x='day', y='sales', color='skyblue')
plt.title('Sales per day')
plt.show()   # axis labels come from column names automatically
⚠️ Common beginner mistakes
  • Forgetting plt.show() in a .py script, so no window appears. Jupyter shows plots automatically.
  • x and y of different lengths give ValueError: x and y must have same first dimension.
  • Calling plt.plot() twice draws on the same chart. Call plt.figure() first to start a new chart.
  • Using a line chart for unordered categories. Use a bar chart there.

Module 3 · Subplots & Multiple Plots

Several charts in one figure: grids, shared axes, GridSpec and mosaics.

🎯 Learning objectives
  • Create grids with plt.subplots(nrows, ncols) and index the axes array
  • Share axes with sharex/sharey; fix overlaps with tight_layout / constrained_layout
  • Build uneven layouts with GridSpec and subplot_mosaic
  • Plot several series on one axes, or one series per axes
💬 In simple wordsOne picture can hold many charts. The whole picture is the Figure, and each chart in it is an Axes. plt.subplots(2, 3) makes 2 rows and 3 columns of charts.

Two ways to put several lines on one chart

Use overlay to compare lines directly. Use separate charts when the lines would be too crowded.

OVERLAY: many lines, one axes
x = np.linspace(0, 10, 100)
plt.plot(x, np.sin(x), label='sin')
plt.plot(x, np.cos(x), label='cos')
plt.plot(x, np.sin(x)*np.cos(x), label='sin·cos')
plt.legend()
plt.show()
SEPARATE: one axes per series
fig, axes = plt.subplots(1, 3, figsize=(12, 3))
axes[0].plot(x, np.sin(x)); axes[0].set_title('sin')
axes[1].plot(x, np.cos(x)); axes[1].set_title('cos')
axes[2].plot(x, np.sin(x)*np.cos(x)); axes[2].set_title('sin·cos')
plt.tight_layout()
plt.show()

GridSpec: full control of spans and ratios

GridSpec lets a chart cover several grid cells, so charts can have different sizes.

import matplotlib.gridspec as gridspec

fig = plt.figure(figsize=(10, 6), constrained_layout=True)
gs = gridspec.GridSpec(3, 3, figure=fig,
                       width_ratios=[2, 1, 1], height_ratios=[1, 1, 2])

ax_big   = fig.add_subplot(gs[0:2, 0])   # rows 0-1, column 0
ax_top   = fig.add_subplot(gs[0, 1:])    # row 0, columns 1-2
ax_mid   = fig.add_subplot(gs[1, 1:])
ax_wide  = fig.add_subplot(gs[2, :])     # whole bottom row

for name, ax in zip(['big', 'top', 'mid', 'wide'], [ax_big, ax_top, ax_mid, ax_wide]):
    ax.set_title(name)
plt.show()

Seaborn's figure-level grids (automatic subplots)

These Seaborn commands make one chart for each value in a column, without you building the grid.

tips = sns.load_dataset('tips')
# one subplot per value of 'time' (columns) and 'sex' (rows)
sns.relplot(data=tips, x='total_bill', y='tip', col='time', row='sex', hue='smoker', height=3)
sns.displot(data=tips, x='total_bill', col='day', col_wrap=2, kde=True)
sns.catplot(data=tips, x='day', y='total_bill', col='time', kind='box')

g = sns.FacetGrid(tips, col='day', col_wrap=2, height=3)   # build your own
g.map_dataframe(sns.scatterplot, x='total_bill', y='tip')
g.set_titles('{col_name}')
⚠️ Figure-level vs axes-levelrelplot / displot / catplot / lmplot / pairplot / jointplot create their own figure, so you can't pass ax=. Axes-level functions (scatterplot, histplot, boxplot, barplot, …) accept ax=axes[0,1] and go inside your subplot grid.

Groups of charts: subfigures and add_gridspec

In simple words: subfigures cuts one figure into separate parts, and each part can have its own title and its own grid of charts. add_gridspec is a shorter way to create the GridSpec from section 3.5.
Use it when: your figure has clear sections, such as 'Sales' on the left and 'Costs' on the right.

fig = plt.figure(figsize=(10, 4), layout='constrained')
left, right = fig.subfigures(1, 2)  # split the figure into two parts

left.suptitle('Left part')
ax_l = left.subplots()  # one chart on the left
ax_l.bar(['A', 'B', 'C'], [3, 5, 2])

right.suptitle('Right part')
axes_r = right.subplots(2, 1, sharex=True)  # two charts on the right
axes_r[0].plot([1, 2, 3], [1, 3, 2])
axes_r[1].plot([1, 2, 3], [3, 1, 2])
plt.show()

fig = plt.figure(figsize=(8, 3), layout='constrained')
gs = fig.add_gridspec(1, 3)  # 1 row, 3 columns
ax_wide = fig.add_subplot(gs[0, :2])  # covers the first two columns
ax_wide.set_title('gs[0, :2]')
ax_small = fig.add_subplot(gs[0, 2])  # the last column
ax_small.set_title('gs[0, 2]')
plt.show()

Module 4 · Working with Axes

Limits, scales, ticks, spines, twin axes and tick formatting.

🎯 Learning objectives
  • Set axis limits, and switch between linear and log scales
  • Control tick positions, labels, rotation and direction
  • Hide or move spines, and invert an axis
  • Format ticks as %, currency or dates; use twin axes carefully
💬 In simple wordsThis module controls the parts around your data: which range is visible (limits), how numbers are spaced (scale), the small marks on the axis (ticks) and the border lines (spines).

🎛️ Axes Lab: exponential growth data

Try the limits, scale and ticks here. The data grows very fast, so the log scale makes a big difference.

Linear vs log scale: why it matters

On a linear scale, each step adds the same amount. On a log scale, each step multiplies, as in 1, 10, 100.

💡 When to use log scaleUse it when the values cover several orders of magnitude (population, virus cases, income, earthquake energy). On a log scale, exponential growth becomes a straight line, which is easy to read.

Tick locators & formatters

A locator decides where ticks go. A formatter decides how they are written, such as 25% or ₹12,000.

from matplotlib.ticker import (MultipleLocator, MaxNLocator, AutoMinorLocator,
                               PercentFormatter, FuncFormatter, StrMethodFormatter)
import matplotlib.dates as mdates

ax.xaxis.set_major_locator(MultipleLocator(2))       # a tick every 2 units
ax.xaxis.set_minor_locator(AutoMinorLocator(4))      # 4 minor ticks between majors
ax.yaxis.set_major_locator(MaxNLocator(nbins=5, integer=True))

ax.yaxis.set_major_formatter(PercentFormatter(xmax=1))           # 0.25 → 25%
ax.yaxis.set_major_formatter(StrMethodFormatter('₹{x:,.0f}'))    # 12000 → ₹12,000
ax.yaxis.set_major_formatter(FuncFormatter(lambda v, pos: f'{v/1e6:.1f}M'))

# dates on x-axis
ax.xaxis.set_major_locator(mdates.MonthLocator())
ax.xaxis.set_major_formatter(mdates.DateFormatter('%b %Y'))   # Jan 2026
fig.autofmt_xdate()                                            # auto-rotate date labels

Twin axes (two y-scales): use with care

twinx() adds a second y-axis, so two values with different units can share one chart.

fig, ax1 = plt.subplots()
ax1.plot(months, temp, color='tab:red')
ax1.set_ylabel('Temperature (°C)', color='tab:red')
ax1.tick_params(axis='y', labelcolor='tab:red')

ax2 = ax1.twinx()                      # shares the x-axis
ax2.bar(months, rain, alpha=0.3, color='tab:blue')
ax2.set_ylabel('Rainfall (mm)', color='tab:blue')
plt.show()
⚠️ CautionTwo y-scales can mislead, because changing either scale moves the lines' crossing point anywhere you like. A safer default is two stacked subplots with sharex=True. Teach twinx, and also teach when not to use it.

More axis tools: twiny, secondary_xaxis, axline, autofmt_xdate, autoscale

In simple words: twiny adds a second x-axis on top. secondary_xaxis shows the same values in another unit. axline draws an endless straight line through a point at a given slope. fig.autofmt_xdate() tilts date labels so they do not overlap. autoscale fits the limits back around the data after you changed them.

fig, axes = plt.subplots(1, 3, figsize=(15, 3.6))

# A second x-axis on top, with its own values
axes[0].plot([0, 1, 2], [1, 3, 2])
axes[0].set_xlabel('bottom axis')
top = axes[0].twiny()
top.plot([0, 100, 200], [2, 1, 3], color='C1')
top.set_xlabel('top axis (twiny)')

# The same value in a second unit: metres and feet
axes[1].plot([0, 10, 20], [0, 5, 3])
axes[1].set_xlabel('metres')
feet = axes[1].secondary_xaxis(
    'top', functions=(lambda m: m * 3.281, lambda f: f / 3.281)
)
feet.set_xlabel('feet (secondary_xaxis)')

# An endless line through (0, 0) with slope 1
axes[2].scatter([1, 2, 3, 4], [1.2, 1.9, 3.3, 3.8])
axes[2].axline((0, 0), slope=1, color='gray', ls='--')
axes[2].set_title('axline', pad=10)
axes[2].autoscale()  # fit the limits around the data again

plt.tight_layout()
plt.show()

# Tilted date labels
fig, ax = plt.subplots(figsize=(7, 3))

💬 In simple wordsSo far we used plt., which works on the current chart. Here you keep the chart in a variable (ax) and tell it what to do, as in ax.plot(). This is clearer when a figure has many charts.

🔍 Interactive anatomy of a figure: click a part

Click a part on the list to highlight it on the chart.

The hierarchy

A Figure holds Axes (charts). Each Axes has an x-Axis and a y-Axis. Everything drawn is called an Artist.

Figurethe whole window / page
Axesone plot area (many per figure)
Axisx-axis & y-axis (ticks, labels)
Artistslines, text, patches…

Axes ≠ Axis. An Axes is a whole plot. An Axis is one of its number lines.

Two interfaces: hover a row to see the translation

These are two ways to write the same chart. Most plt.xxx commands become ax.set_xxx.

🅰️ pyplot (state-based)

Quick and short, good for quick looks. pyplot keeps track of the "current" axes for you.

🅱️ Object-oriented (explicit)

You hold fig and ax yourself. Recommended for subplots, functions and production code.

Colormaps: click one to copy its name

A colormap turns numbers into colours. Use one colour fading out for low-to-high values, and two colours for values above and below a centre.

💬 In simple wordsSaving turns your chart into a file. Use PNG for slides and documents, and SVG or PDF when it must stay sharp at any zoom. dpi sets the sharpness of PNG files: a higher dpi means more detail and a bigger file.

🎛️ savefig() Builder

Choose the options and see the exact command. dpi sets sharpness, and bbox_inches='tight' stops labels being cut off.

⏱️ The #1 bug: order of show() and savefig()

plt.show() finishes the figure. If you save after it, the saved image is blank. So always save first.

❌ Wrong: saves a BLANK image
plt.plot(x, y)
plt.show()            # shows the figure, then closes it
plt.savefig('a.png')  # saves a new, empty figure
✅ Right: save first, then show
plt.plot(x, y)
plt.savefig('a.png', dpi=300, bbox_inches='tight')
plt.show()
# or, safest: fig.savefig(...) on a figure you hold

Glossary

The main words used in this course, in simple language.

WordMeaning
FigureThe whole picture. It can hold one or many charts.
AxesOne chart area inside a figure.
AxisOne number line of a chart (x or y).
ArtistAnything drawn: a line, some text, a bar.
pyplot / pltThe Matplotlib commands for quick charts.
DataFrameA table of rows and columns, from pandas.
TickA small mark on an axis, with its number or name.
SpineOne of the four border lines of a chart.
LegendThe small box that says what each line or colour means.
MarkerThe shape drawn at each data point.
AlphaTransparency: 0 is invisible and 1 is solid.
BinOne range of values in a histogram.
DistributionHow the values of a column are spread out.
Mean / MedianThe average / the middle value when sorted.
QuartileValues that cut sorted data into four equal parts. Q1 is 25% of the way, Q3 is 75%.
OutlierA value far away from the others.
SD (standard deviation)How spread out values are around the average.
CI (confidence interval)A range where the true value probably lies.
KDEA smooth curve that shows the shape of the data.
ECDFA rising line showing what share of values lie below each x.
CorrelationHow strongly two columns move together, from -1 to 1.
RegressionFinding the line that best fits the points.
Colormap / PaletteA range of colours for numbers / a set of colours for groups.
dpiDots per inch. A higher value makes a sharper image.
Raster / VectorAn image made of pixels / an image made of shapes that stay sharp.
rcParamsMatplotlib's list of default settings.
BackendThe part of Matplotlib that actually draws the chart. Agg draws images without a screen.
EDAExploratory data analysis: looking at data with charts before doing anything else.
